SmartCare-Clinic OOP capstone

A terminal-based clinic appointment and diagnosis simulation that applies core object-oriented programming concepts in one coherent program.

▢ Preview image coming soon

What it does

Auto-generates patient IDs, routes symptoms to the right specialty, flags urgent cases (chest pain, fractures), assigns doctors, and bills with an urgency surcharge — with colored terminal output for readability.

What it covers

Inheritance (Patient, Doctor, Receptionist from Person), polymorphism across introduce() and apply(), encapsulation via private attributes with getters, abstract base classes for Person and Treatment, and operator overloading (__lt__, __gt__, __str__) for sorting and printing appointments.

File Organizer Automation First shipped project

A command-line utility that organizes files into folders by type and date while avoiding risky moves when a file is still in use.

▢ Preview image coming soon

What it does

Scans target folders, sorts files into type-based directories (Images, Documents, Videos, Music), organizes by date created, creates destination folders on the fly, and skips open files gracefully instead of crashing mid-run.

What I learned

Handling real filesystem edge cases — not every file can be moved safely, and a script that crashes on a locked file isn't done yet. pathlib and shutil over manual string path handling.

FreelanceLens Data analysis

A small data analysis project that explores manually collected freelance listings to identify common skills, categories, and budget patterns.

▢ Preview image coming soon

What it does

Cleans listing data to surface the most in-demand skills, average budget by category — fixed-price and hourly kept separate, since mixing the two would be meaningless — and the most common job category.

What I learned

Small sample sizes lie if you let them: categories with only 2–3 listings get their average reported alongside the sample size, not treated as reliable. Budget ranges were recorded at their minimum value — a known bias I documented rather than hid.
