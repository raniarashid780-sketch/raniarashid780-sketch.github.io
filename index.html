SmartCare-Clinic

OOP capstone → REST API → Dockerized

A clinic appointment and diagnosis system that started as a terminal-based OOP project and grew into a full REST API. Auto-generates patient IDs, routes symptoms to the right specialty, flags urgent cases, assigns doctors, and bills with an urgency surcharge — backed by PostgreSQL via SQLAlchemy, versioned Alembic migrations, and a FastAPI layer that enforces no-double-booking at the database level, all containerized with Docker Compose so it runs with one command, no local Postgres install required.

What I learned. Beyond the original OOP work (inheritance, polymorphism, encapsulation, ABCs, operator overloading): SQLAlchemy 2.0 ORM modeling, Alembic migrations (including adopting an existing hand-built schema instead of dropping/recreating), FastAPI dependency injection for session lifecycle, and designing a layered architecture (models/schemas/crud/service/routes) so business logic is reused, not duplicated, across the terminal app and the API. Most recently: multi-container Docker orchestration — service networking, healthchecks to solve startup-ordering races, persistent volumes, and rebuilding a migration history that had silently depended on a hand-run schema.sql instead of being self-contained.

FreelanceLens

Data analysis

A small data analysis project exploring manually collected freelance listings to identify common skills, categories, and budget patterns — fixed-price and hourly kept separate.

What I learned. Small sample sizes lie if you let them: categories with only 2–3 listings get their average reported alongside the sample size. Budget ranges were recorded at their minimum value — a known bias I documented rather than hid.
